# 個人化AI健康助手 (Healthcare Companion v0.3)

## 專案簡介

這是一個個人化的AI健康助手應用程式，旨在幫助用戶管理個人健康資訊、追蹤健康指標、安排醫療預約，並在緊急情況下提供快速協助。

## 功能特色

### 🏥 健康管理
- **健康指標追蹤**: 血壓、心率、血糖等關鍵健康數據監控
- **用藥管理**: 藥物提醒、劑量追蹤、副作用記錄
- **醫療預約**: 預約管理、提醒通知、醫療記錄整合

### 📊 數據視覺化
- 健康趨勢圖表
- 個人化健康報告
- 數據匯出功能

### 🚨 緊急功能
- 緊急聯絡人快速撥號
- 關鍵醫療資訊快速存取
- 位置分享功能

### 👤 個人化設定
- 個人健康檔案
- 偏好設定
- 通知管理

## 技術架構

- **前端框架**: React 18
- **UI 組件**: 自定義組件 + Tailwind CSS
- **圖表庫**: Recharts
- **動畫**: Framer Motion
- **路由**: React Router
- **部署**: GitHub Pages
